# La vie des plantes

## Description

Ce projet a été réalisé dans le cadre de ma formation Développeur Web.

Il s'agit d'un site vitrine WordPress pour l'entreprise fictive **La vie des plantes**.

Le site présente :

- une page d'accueil ;
- une boutique ;
- une page À propos ;
- une page Contact.

Le site a été réalisé avec :

- WordPress
- Elementor
- WooCommerce
- Local
- Git
- GitHub

## Installation

1. Cloner le dépôt.
2. Importer le projet dans Local (ou un environnement WordPress).
3. Configurer la base de données.
4. Lancer le site.
